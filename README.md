# AI Photo & Video Authenticity Checker

## Overview
The **AI Photo & Video Authenticity Checker** is a web application that helps users tell whether a photo or video was made by a human or generated by Artificial Intelligence. It is designed to be accessible and easy for older adults to use.

This project was built for a Software Engineering course. It uses two custom-trained Convolutional Neural Networks (CNNs) built with PyTorch: one for photos and one for videos. A Python Flask backend serves the models, and the frontend is plain HTML/CSS/JS with high contrast.

## Features
* **Senior-Friendly UI/UX:** Large text, warm high-contrast colors, clear step-by-step instructions and large buttons designed for older adults.
* **Photo Detection:** A custom PyTorch `ImageCNN` model classifies images as "Human-Made" or "AI-Generated".
* **Video Detection:** A custom PyTorch `CustomCNN` model (with batch normalization) analyses uploaded videos. The backend uses OpenCV to sample **1 frame out of every 15**, classifies each sampled frame, and averages the probabilities into a single verdict.
* **Confidence Scoring:** Shows the model's confidence percentage next to the prediction.
* **Safety & Transparency:** Every result includes a disclaimer about AI errors (false positives/negatives), so users don't rely on the tool for important decisions.
* **Single File Processing:** Users can upload only one file at a time, on both the frontend and the backend. A loading bar shows while the file is processed.

## Tech Stack
* **Frontend:** HTML5, CSS3 (custom warm theme)
* **Backend:** Python, Flask
* **Machine Learning:** PyTorch, Torchvision, Pillow, Scikit-learn, NumPy
* **Video Processing:** OpenCV (`cv2`)
* **Testing:** pytest, unittest

## Installation & Setup

### Prerequisites
* Python 3.8 or higher
* Git (optional, for cloning)

### Step-by-Step Guide
1. **Go to the project folder:**
   ```bash
   cd path/to/wbesite_for_ai_checking
   ```

2. **Create a virtual environment (recommended):**
   ```bash
   python -m venv venv
   ```
   * Activate on Windows: `.\venv\Scripts\activate`
   * Activate on Mac/Linux: `source venv/bin/activate`

3. **Install dependencies:**
   ```bash
   pip install -r requirmenets.txt
   ```

4. **Add the model weights:**
   * `video_cnn_weights.pth` is included in the repository.
   * `image_cnn_weights.pth` is **not** in the repository right now. Generate it by running `images_train-test.ipynb`, or copy it into the project root. If it is missing, the server still starts but prints a warning, and photo predictions will come from an untrained model.

5. **Run the server:**
   ```bash
   python app.py
   ```

6. **Open the website:**
   In your web browser, go to **`http://127.0.0.1:5000`**.
   *(Note: Don't open the site with VS Code Live Server (port 5500). It can't run the Python backend.)*

## Usage
1. Open the application in your browser.
2. On the main menu, choose to check a **Photo** or a **Video**.
3. Click the upload area and select a single file from your device.
4. Click **Check This Picture/Video**. A loading bar appears while the backend processes the file.
5. View the results: the classification, a confidence score and a disclaimer about the tool's accuracy.

## API Endpoints
| Method | Route           | Description                                                        |
|--------|-----------------|--------------------------------------------------------------------|
| GET    | `/`             | Serves `index.html` and the other static files                     |
| POST   | `/upload-photo` | Takes one image (`file` field) and returns an HTML result page     |
| POST   | `/upload-video` | Takes one video (`file` field) and returns an HTML result page     |

Both upload routes return `400` if no file is sent or more than one file is sent, and `500` if processing fails.

## Training the Models

### Photo model
Open `images_train-test.ipynb` and run all cells. It trains `ImageCNN` on 224×224 images and saves `image_cnn_weights.pth`.

### Video model
1. Put the raw videos in `data_sample/data_sample/videos/` (for example `real_english/` and `fake_english/`). Folders or files with `fake` in their path are labelled fake; folders with `real` are labelled real.
2. Open `video code.ipynb` and run all cells. The notebook:
   * extracts 1 frame out of every 15 into `video_frames/real` and `video_frames/fake`,
   * splits the data **by video, not by frame**, so frames from the same video can't end up in both train and test (this prevents data leakage),
   * trains `CustomCNN` on 128×128 frames,
   * saves `video_cnn_weights.pth`.

## Running the Tests
Run this from the project root:
```bash
pytest tests
```
Some video tests use the extracted frames in `video_frames/`. Run `video code.ipynb` first if that folder is empty.

## Model Details & Limitations
* **Photo model:** `ImageCNN`, 3 convolutional layers, trained on a small dataset (about 200 images).
* **Video model:** `CustomCNN`, 4 convolutional layers with batch normalization and adaptive pooling. It classifies sampled frames and averages them, so it doesn't use motion or audio between frames.
* **Disclaimer:** Both datasets are small, so the models are not very accurate on real-world media. The project is a proof of concept for the software engineering pipeline (client-server architecture), not a production-ready forensic tool.
* **Future Work:** Use pre-trained backbones (e.g., ResNet50, EfficientNet) with transfer learning on larger datasets of AI-generated and real media. For video, add temporal models that look at how frames change over time.
